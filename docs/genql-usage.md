# Frontend GraphQL Integration (GenQL)

The GraphFolio frontend (Web) connects to the Backend-for-Frontend (BFF) using a fully typed GraphQL client generated by [GenQL](https://genql.dev/).

GenQL inspects our GraphQL schema and generates a lightweight, strictly-typed query builder. This means you get full TypeScript autocompletion when fetching data from the BFF, catching schema mismatches at compile-time instead of runtime.

## 1. How it works

1. The BFF exposes a GraphQL schema at `bff/graph/schema.graphqls`.
2. The `@genql/cli` reads this schema and outputs a generated TypeScript client into `web/src/generated`.
3. The React components in `web/src` import this client to execute queries.

## 2. Generating the Client

Whenever the GraphQL schema in the BFF is modified, you **must** regenerate the frontend client so TypeScript is aware of the new fields.

We have a unified command for this in the root `Makefile`:

```bash
make generate
```

Under the hood, this executes the following command in the `web` directory:
```bash
npx genql --schema ../bff/graph/schema.graphqls --output ./src/generated
```

## 3. Using the Client in React Components

The generated client allows you to write GraphQL queries using plain JavaScript objects. 

### Instantiating the Client

The client is typically instantiated once and reused. See `Dashboard.tsx` for an example:

```typescript
import { createClient } from '../generated';

const client = createClient({
  url: 'http://localhost:8080/query', // The BFF endpoint
});
```

### Fetching Data

Queries are structured to map exactly to the GraphQL schema. Set the fields you want to fetch to `true`.

```typescript
useEffect(() => {
  client.query({
    portfolio: {
      totalValue: true,
      cashBalance: true,
      investments: {
        id: true,
        ticker: true,
        price: true,
        quantity: true,
      }
    }
  })
  .then(res => {
    // res.portfolio is fully typed!
    setData(res.portfolio);
  })
  .catch(err => {
    console.error("GraphQL Error:", err);
  });
}, []);
```

Because `res.portfolio` is typed based on the schema, your IDE will provide autocomplete for properties like `res.portfolio.totalValue` and warn you if you attempt to access fields you didn't request in the query.
