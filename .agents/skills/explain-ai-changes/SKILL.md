name: explain-ai-changes
description: Use when the user asks to review, summarize, or explain recent changes, PRs, or commits generated by an AI coding agent. Analyzes architectural impact, design choices, and potential risks.
---

## Context
When invoked, inspect the current uncommitted changes or the latest git commit using dynamic context injection:

!`git diff HEAD`

## Instructions

1. **Categorize the Changes:** Group modifications into logical buckets (e.g., Core Architecture, Business Logic, Tests, Configuration/Infra).
2. **Analyze Agent Intent:** Briefly describe *why* these changes were likely made based on the diff patterns and surrounding codebase structure.
3. **Highlight Architectural Shifts:** Call out any new abstractions, dependency changes, or shifts in design patterns introduced by the agent.
4. **Risk & Safety Assessment:** Scan the changes for common AI blind spots, such as:
   - Missing error handling or unhandled edge cases.
   - Hardcoded values or magic strings.
   - Unused imports or dead code left behind.
   - Test coverage gaps.

Keep the summary clear, concise, and structured for a senior engineer or architect.
